# Материалы для магазинов

Приложение и сайт — разные репозитории. Сюда ничего из приложения не пушится.

В отдельный репозиторий Pages скопируй **всё** из `pages/` в корень (не в подпапку):

- `index.html`
- `privacy.html`
- `support.html`
- `terms.html`
- `style.css`
- `favicon.png`
- `.nojekyll` — тоже. Это не файл приложения. Он нужен GitHub Pages, чтобы сайт отдавался как обычный HTML, без Jekyll.
